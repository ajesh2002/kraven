# KRAVEN

Mobile web app for KRAVEN, built with React, TypeScript and Vite.

## Screens

- **Home / Browse Categories**: header, a 2-column grid of category cards, a Loyalty Points banner and the bottom tab bar.
  The cards and banner stretch to fill the height left between the header, the title and the tab bar, so the
  whole dashboard fits on one phone screen without scrolling.

## Development

```bash
npm install
npm run dev
```

```bash
npm run build
```
